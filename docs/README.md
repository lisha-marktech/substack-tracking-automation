# Project Documentation

Welcome to the technical documentation for the **Substack Tracking Automation** project.

This folder contains detailed implementation notes, architecture documentation, debugging history, and tracking setup for an end-to-end conversion tracking system built for **The Automation Diary**.

## Documentation Roadmap

### 1. Architecture

Explains how data flows between Substack, Google Tag Manager, GA4, Google Ads, and Meta Pixel.

**File:** `architecture.md`

### 2. Google Tag Manager Setup

Documents every tag, trigger, variable, and custom event used for conversion tracking.

**File:** `gtm-setup.md`

### 3. Google Analytics 4 Events

Documents GA4 custom events, conversions, and validation using DebugView.

**File:** `ga4-events.md`

### 4. Google Ads Conversion Tracking

Documents conversion actions, campaign setup, bidding strategy, and debugging notes.

**File:** `google-ads.md`

### 5. Meta Pixel Setup

Documents Meta Pixel installation, Lead event configuration, campaign objective, and debugging history.

**File:** `meta-pixel.md`

### 6. Debugging Notes

Documents real implementation issues encountered during this project and how they were resolved.

**File:** `../notes/debug-log.md`

## Project Goal

Build an end-to-end conversion tracking system for a Substack publication using first-party event tracking through GTM and GA4, then send conversion signals to Google Ads and Meta Ads for campaign measurement.
