# Substack Tracking Automation

## Project Overview

This project documents an end-to-end conversion tracking implementation for my publication **The Automation Diary**.

The goal was to track newsletter subscription intent across multiple marketing platforms using Google Tag Manager (GTM), Google Analytics 4 (GA4), Google Ads, and Meta Pixel.

## Business Goal

Measure newsletter subscription actions and send conversion data to advertising platforms for campaign optimization and reporting.

## Tools Used

* Google Tag Manager
* Google Analytics 4
* Google Ads
* Meta Ads Manager
* Meta Pixel
* JavaScript
* Substack
